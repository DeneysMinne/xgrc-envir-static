# XGR Static Demos

Interactive static dashboards for risk and carbon insights.

## Local development

```bash
npm install
npm start
```

Open http://localhost:3000

## Deploy to Railway

Push to GitHub. Railway auto-deploys on every commit to main.

## Adding new dashboards

Drop additional `.html` files into `/public` and they are immediately accessible at:
`https://your-app.up.railway.app/filename.html`
